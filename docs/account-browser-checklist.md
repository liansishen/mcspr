# 账户与实例授权：浏览器验收清单

浏览器验证由用户实施。建议使用独立面板数据目录，准备管理员账户、普通用户 A / B 和实例 A / B。操作性回归使用测试实例，避免影响生产世界。本清单覆盖注册审批、游戏名变更、实例权限、全局操作反馈、任务中心、顶栏 / 页脚 / 侧栏与四套主题。

自动化范围（由助手执行）：`cargo test`、`node --check web/app.js`、`node --test tests/*.test.cjs`、本机接口回归及测试实例启动 / 停止。浏览器端到端步骤由用户操作，结果待用户确认。

## 本机验收环境

- 本机入口：`http://127.0.0.1:18082`；同一局域网：`http://192.168.3.230:18082`。
- 服务：`mcspr-feature-demo.service`；独立目录：`/root/temp/mcspr-feature-demo-20261009`，实例和账户位于其 `data/` 子目录。
- 测试账户保存在该目录的 `credentials.json`，包含管理员、已批准用户、待审批用户、已拒绝用户和零授权用户。密码仅保存在本机私有文件中。
- 主要实例为「功能验收 · 原版 1.20.1」，已安装服务端 JAR、接受 EULA，并使用离线身份模式；第二实例用于授权范围测试，可保持停止状态。
- 注册已开启，Turnstile 显式测试模式使用官方测试配置。正式 Siteverify 的联网、主机名和令牌过期行为需使用实际站点配置验收。
- 建议管理员和普通用户分别使用两个浏览器或独立隐私窗口，以验证审批、撤权及跨页数据一致性。
- 自动化接口验证完成后，浏览器验收结果仍由用户在清单中记录。原有 `18081` 服务单独运行。

## 1. 账户登录与管理

- 管理员使用用户名和密码登录，确认原有仪表盘、实例管理和面板设置入口可用。
- 在账户管理页创建两个普通用户，分别分配实例 A 和实例 B。
- 修改账户启用状态、重置密码；确认新密码可登录，原会话需要重新登录。
- 使用错误密码登录，检查错误提示；退出后刷新与浏览器返回键均应保持登录页。
- 修改自己的密码，确认修改后的登录流程。
- 在同一浏览器退出管理员后登录普通用户，检查导航、实例内容和按钮与角色一致。
- 在开发者工具中限制网络速度，退出后重新登录；确认旧请求的迟到响应不会退出新会话，登录页没有持续业务轮询。
- 右上角账户菜单显示固定注册用户名（长名省略并可悬停查看全名）、角色与游戏名；菜单含个人资料、修改密码、退出。

## 2. 注册、人机验证与申请状态

- 面板设置中确认「开放公开注册」和「测试模式」已开启；确认注册页可用（测试模式使用官方测试令牌 `XXXX.DUMMY.TOKEN.XXXX`）。
- 打开 `#/register`：填写用户名、密码、确认密码、Minecraft 游戏名、申请理由；确认游戏名仅接受 `^[A-Za-z0-9_]{1,16}$`。
- 测试模式提交后显示「申请已提交，等待管理员审批」；确认密码不写入 localStorage / sessionStorage。
- 关闭公开注册后重新打开注册页，确认提交按钮禁用并提示未开放注册。
- 配置真实站点密钥并关闭测试模式；断网或使用广告拦截使 Turnstile 脚本加载失败，确认显示重试提示且不能提交。
- 等待 Turnstile 令牌过期后再次提交，确认组件刷新（`resetTurnstile`）并给出可重试状态。
- 打开 `#/status`，用注册用户名和密码查询：待审批显示状态；错误密码统一提示且不泄露账户是否存在。
- 管理员拒绝并填写理由；用户再次查询看到拒绝理由，修改游戏名 / 理由后重申，状态回到待审批。

## 3. 管理员审批与游戏名变更

- 账户管理页「注册 / 改名申请」标签页显示待审批数量徽标、筛选与详情。
- 批准注册申请：可勾选分配实例（可为空），确认后账户可登录且仅能看到已授权实例。
- 拒绝申请必须填写理由；确认理由展示给申请人。
- 普通用户在个人资料页提交游戏名变更；确认等待期间旧游戏名与登录继续生效，可撤回申请。
- 管理员批准改名：确认相关实例白名单同步结果；部分失败时显示「白名单同步待处理」并提供重试。
- 批准后再次登录普通用户，确认游戏名与实例访问范围一致。

## 4. 普通用户实例权限

- 用户 A 仅看到实例 A，用户 B 仅看到实例 B。
- 新建一个零授权用户，确认显示「管理员尚未分配实例」。
- 普通用户进入实例，默认打开公告，标签顺序为「公告」「运行信息」；确认没有管理员标签页（含「用户权限」）。
- 输入其他实例地址、管理员页面地址、控制台或文件标签地址，确认安全提示或跳转。
- 管理员在实例详情「用户权限」标签页按用户名 / 游戏名检索，勾选授权并保存；确认修订号冲突时提示并刷新。
- 在普通用户已打开实例时，由管理员撤销权限，等待下一次刷新；确认旧数据清理、刷新停止。
- 查看实例权限页的「白名单同步」提示：待处理成员 / 最近错误时显示警告，点「重试同步」调用重试接口并刷新状态。
- 浏览器开发者工具中查看实例列表与详情响应，确认只返回普通用户所需字段。
- 检查白名单同步保留手动玩家和 `white-list` 开关；分别设置正版 / 离线身份覆盖，并检查代理服部署提示。
- 批准改名后检查旧名预留：在任一实例保留手动旧名条目时，其他申请无法占用旧名；移除条目并完成同步后可再次申请。
- 同步失败、无游戏服配置、白名单 JSON 异常等状态应显示具体原因；重新检查后任务中心反映重试结果。
- 检查 `enforce-whitelist` 说明，并确认面板同步过程保持不主动踢人。

## 5. 全局操作反馈与重复提交保护

- 对任一写操作（保存设置、启动 / 停止、删除、上传、审批、授权等）快速双击或连续回车，确认只产生一次副作用，按钮立即进入忙碌状态并在结束后恢复。
- 开发者工具 Network 中确认写请求带 `X-Operation-ID` 头，且同一逻辑操作重试时编号稳定。
- 断开网络后触发写操作，确认提示「结果待确认」，恢复网络后任务中心 / 操作编号查询能反映真实结果。
- 上传模组 / 文件 / 整合包：进度到 100% 后显示「服务器处理中」，完成后刷新正确资源；期间切换标签页或关闭弹窗不影响结果。
- 上传含非法文件（如 mods 目录上传 .txt）时，确认显示「部分失败」并列出每个失败文件与原因，不把 200 当作全部成功。

## 6. 任务中心与任务恢复

- 右上角任务中心显示活动任务数量徽标；点击展开列表，含标题、类型、状态、进度与日志。
- 启动一个长任务（整合包更新 / 备份 / 导入），关闭弹窗、切换到其它页面；确认任务继续在任务中心跟踪。
- 刷新浏览器；确认任务中心通过 `GET /jobs` 恢复活动与最近完成任务。
- 断网期间任务状态查询失败时给出提示，恢复后自动继续；终止态任务停止轮询。
- 注销或切换账户后确认任务中心与私有状态被清空。

## 7. Markdown 公告

- 管理员输入中文标题、列表、引用、链接、代码块和表格，预览后保存。
- 用户刷新公告，确认内容及更新时间；两个实例的公告独立。
- 清空公告保存，确认普通用户看到空公告提示。
- 在两个管理员窗口编辑同一公告，先保存其中一个，再保存另一窗口，确认冲突提示保留输入。
- 输入 `<script>alert(1)</script>`、带事件属性的 HTML 和 `javascript:` 链接，确认渲染安全。
- 在网络较慢时点击预览或保存，立即切换到另一个实例；确认两个实例的编辑器内容、预览和公告版本分别保持正确。

## 8. 运行信息与时长

- 检查已停止、启动中、运行中、停止中各状态。
- 已配置 TPS 采集的实例，检查数值、采样时间及自动刷新；采集未配置或失败时检查提示。
- 停止后重新启动实例，确认 TPS 重新采集。
- 玩家首次加入后保持在线，确认在线标记、累计时长和当前会话时长持续增长。
- 玩家退出后确认离线标记、累计值保留、当前会话时长归零；再次加入后继续累计。
- 停服后再次启动，确认累计时长保留。

## 9. 管理员既有功能回归

使用测试实例完成以下真实操作：

- 仪表盘与实例列表状态一致，启动 / 停止 / 重启可用。
- 控制台接收历史和实时日志，命令提交可用；WebSocket 断开后的 HTTP 回退恢复正常。
- 游戏玩家管理、模组列表、备份、游戏内备份、世界和计划任务页面可用。
- 文件上传、编辑和下载正常，下载请求使用登录会话。
- 服务器设置、实例设置及面板设置加载与保存正常；面板设置中的注册 / Turnstile 配置可保存，服务端密钥留空保持不变。
- 实例设置中的「白名单身份模式」可选自动 / 正版 / 离线；保存后重新打开确认选择保留。代理转发场景根据实际转发的玩家 UUID 显式选择正版或离线。
- 登录到期、主动退出或账户被禁用后，已有控制台连接关闭。
- 会话失效后尝试下载文件或备份，确认进入登录页；重新登录后下载恢复。
- 管理员打开 TPS 监控，检查未采样、未配置、失败、过期和已停止提示，并检查采样时间使用本地时间。

## 10. 布局、侧栏与主题

在桌面（如 1440×900）和手机（如 390×844、360×800）视口分别检查：登录页、注册页、申请状态页、个人资料页、账户管理、实例列表、实例详情各标签页、长公告、代码块和长玩家表格。

- 桌面：点击侧栏「收起侧栏」，确认切换为仅图标模式、文字提示可用，刷新后偏好保留（localStorage `mcspr.sidebar`）。
- 手机：默认抽屉关闭；点击菜单按钮打开，焦点进入首个导航项；点击遮罩、按 Escape 或点击任一导航项后关闭，焦点回到菜单按钮。
- 顶栏在登录、注册、状态、仪表盘、实例列表、账户管理、面板设置、个人资料和所有实例标签页保持一致；未登录页隐藏业务导航与账户操作，保留主题切换。
- 页脚显示服务端真实版本、Rust / Axum / Tokio 技术栈与 GitHub 链接（`rel="noopener"`），常规页面位于底部，详情页不遮挡表格、控制台与输入框。
- 在深色、亮色、MC 像素、Claude 四套主题下检查文字可读性、任务中心、账户菜单、权限表与页脚一致。表格与代码块在各自区域滚动，表头吸顶，控制台输入框始终可见，操作按钮保持可见。
- 软键盘弹出时详情页布局不溢出，触控目标尺寸可点。
